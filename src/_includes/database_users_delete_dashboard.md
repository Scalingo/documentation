1. From your web browser, open your [database dashboard][database-dashboard]
2. Click the **Settings** tab, then select **Database users**
3. Locate the non-protected user you want to remove
4. Open the **...** menu next to this user, then click **Delete user**
5. In the popup window, confirm the deletion by typing the name of the user
6. Validate by clicking the **Confirm** button
