- **Personal account:** The user receives an invitation by email and must accept
  it to access the resource.
- **Organization:** The user must already be a member of the same organization.
  Access is granted immediately, without another invitation. If they have not
  joined yet, [invite them to the organization]({% post_url platform/user-management/organizations/2000-01-01-managing-members %}#inviting-a-member)
  first and wait for them to accept.
