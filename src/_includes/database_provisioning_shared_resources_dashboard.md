1. From your web browser, open your [dashboard](https://dashboard.scalingo.com/apps)
2. Click on the application to which you want to add the database
3. Click on the **Resources** tab
4. Locate the **Addons** block and click on the **Add an addon** button
5. Select **{{ include.engine }}** in the databases block and click the **Go to plan
   selection** button
6. Select the plan you want to provision
7. Click the **Finish** button
8. Confirm by clicking the **Provision addon** button
9. Wait a few seconds for the database to be provisioned
