1. From your web browser, open your [database dashboard][database-dashboard]
2. Click the **Settings** tab, then select **Database users**
3. Click the **Add a database user** button
4. Fill the **Add a new user** form:
   - Enter a username
   - To grant write permissions to this user, check the **Write (optional)**
     checkbox. Leave it unchecked to create a read-only user.
5. Validate by clicking the **Add this user** button
6. A password is generated automatically and shown in a popup window after
   the user creation. **You will be able to view and copy it only once**.
