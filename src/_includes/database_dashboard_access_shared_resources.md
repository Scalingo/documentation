You can access the database dashboard via the application dashboard:

1. From your web browser, open your [dashboard](https://dashboard.scalingo.com/projects)
2. Open the **Project** containing the application to which your database is linked
3. Click on the application name
4. Click on the **Overview** tab
5. Locate the **Addons** block and click on the **Dashboard** button next to
   the database you want to manage.
