1. From your web browser, open your [database dashboard][database-dashboard]
2. Click the **Settings** tab, then select **Database users**
3. Locate the non-protected user for which you want to reset the password
4. Open the **...** menu next to this user, then click **Reset password**
5. In the popup window, confirm the reset by typing the name of the user
6. Validate by clicking the **Confirm** button
7. A password is generated automatically and shown in a popup window after
   the password reset. **You will be able to view and copy it only once**.
