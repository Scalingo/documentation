Python `3.11.18`, `3.12.16`, `3.13.18`, `3.14.10` and `3.15.2` are now
available.

These are also the new default version for, respectively, Python 3.11, 3.12,
3.13, 3.14, and 3.15.

Python `3.11` is now deprecated, please upgrade to a more recent version as
soon as possible.
