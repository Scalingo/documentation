Webapp Runner `9.0.121.0` and `10.1.59.0` are now available.

Webapp Runner `9.0.121.0 ` is the new default version.

This entry also introduces the availability of **Webapp Runner Main**, a Webapp
Runner that comes without client libraries for Memcached and Redis.

To use this "flavor", set `JAVA_WEBAPP_RUNNER_FLAVOR` to `main`.
