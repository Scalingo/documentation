title: 'New: Application Firewall is now available for all applications'

Application Firewall is now available for all applications: every application
can restrict public HTTP and HTTPS access to allowed IPv4 ranges.

See the [Application Firewall documentation]({% post_url platform/networking/public/2000-01-01-application-firewall %})
to configure your rules.
