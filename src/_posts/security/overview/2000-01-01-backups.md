## English {#en}

### Managed database backups

Backup methods, retention, and recovery options depend on the database engine, architecture, and service class. Backups
handled by Scalingo are encrypted. See the current [database backup policy][backup-policies] and the restore guide for
your database engine.

### Application and external storage

The filesystem in an application container is temporary. Database backups do not include files stored with an external
object-storage provider; arrange those backups with the provider.

## Français {#fr}

### Sauvegardes des bases de données managées

Les méthodes de sauvegarde, la rétention et les options de restauration dépendent du moteur de base de données, de
l'architecture et de la classe de service. Les sauvegardes prises en charge par Scalingo sont chiffrées. Consultez la
[politique de sauvegarde des bases de données (en anglais)][backup-policies] et le guide de restauration du moteur concerné.

### Stockage applicatif et externe

Le système de fichiers d'un conteneur applicatif est temporaire. Les sauvegardes des bases de données n'incluent pas les
fichiers stockés auprès d'un fournisseur externe de stockage objet ; prévoyez ces sauvegardes avec le fournisseur.
