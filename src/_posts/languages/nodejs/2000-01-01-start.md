Node.js is a JavaScript runtime commonly used for web applications, APIs, background workers, and command-line tools.

Scalingo deploys Node.js applications with its official Node.js buildpack, compatible with the Heroku buildpack ecosystem.

## Detection

Scalingo detects a Node.js application when a `package.json` file is present at the root of the project.

Meteor applications can also be detected when a `.meteor` directory is present at the root of the project.

## Node.js Release Cycle

Node.js follows the upstream Node.js release lifecycle. For production applications, the Node.js project recommends using Active LTS or Maintenance LTS releases.

See the [official Node.js release schedule](https://nodejs.org/en/about/previous-releases) for details about Current, LTS, Maintenance, and End-of-Life releases.

## Available Node.js Versions

The following Node.js release lines are supported on Scalingo:

| Node.js version | Status  | scalingo-22     | scalingo-24     | scalingo-26     |
| --------------- | ------- | --------------- | --------------- | --------------- |
| `26`            | Current | up to `26.8.2`  | up to `26.8.2`  | up to `26.8.2`  |
| `24`            | LTS     | up to `24.21.0` | up to `24.21.0` | up to `24.21.0` |
| `22`            | LTS     | up to `22.23.2` | up to `22.23.2` | up to `22.23.2` |

End-of-Life Node.js releases are not supported.

See [Selecting a Node.js Version](/languages/nodejs/selecting-a-version) to choose the version used by your application. For the version used when none is specified, see [Default Behavior](/languages/nodejs/default-behavior).

## Package Managers

The Node.js buildpack supports the following package managers:

* [npm](/languages/nodejs/npm)
* [Yarn](/languages/nodejs/yarn)
* [pnpm](/languages/nodejs/pnpm)

See [Default Behavior](/languages/nodejs/default-behavior) for how Scalingo determines which package manager to use.
